# Kernelios Academy

Hebrew learning portal for LPI Linux Essentials 010-160 (version 1.6).

Open `index.html` in a modern browser. No server or build step is required.

- Six study topics with terminal examples and short practice tasks.
- Three simulated Linux rooms with flags and browser-local completion status.
- To use the exam simulator, select the supplied `simulator` Bash file in the portal. The browser reads it as question data without executing the script or uploading it. Its questions remain under the original author's attribution.

[Open Kernelios Academy](https://yaronma123.github.io/kernelios-demo-site/). GitHub Pages deploys from `main`.
