הפצות Linux וקוד פתוח

הפצה משלבת את ליבת Linux עם כלי מערכת, חבילות ומאגרי תוכנה. Ubuntu ו־Debian משתמשות ב־APT. הפצות ממשפחת Fedora משתמשות ב־DNF.

cat /etc/os-release
uname -r
apt search tree
  • זהו את ההפצה, את גרסת הליבה ואת שם החבילה שמציגה עץ תיקיות.
  • הסבירו למה מנהל חבילות מתקין גם תלויות.
טרמינל, קבצים ותיקיות

נתיב מוחלט מתחיל ב־/. נתיב יחסי מחושב מהתיקייה הנוכחית. אפשר לעיין באפשרויות של פקודה דרך man.

pwd
ls -la
mkdir -p ~/practice/reports
find ~/practice -type d
man ls
  • צרו את התיקייה והציגו אותה פעם בנתיב מוחלט ופעם בנתיב יחסי.
עיבוד טקסט, ארכיונים ו־Bash

התו | מעביר את הפלט של פקודה לפקודה הבאה. השתמשו בו לסינון ולספירה, וב־tar כדי לארוז קבצים.

cut -d: -f1 /etc/passwd | sort | head -n 5
tar -czf practice.tar.gz -C "$HOME" practice
tar -tzf practice.tar.gz
for file in "$HOME"/practice/*; do
  printf '%s\n' "$file"
done
  • צרו את תיקיית התרגול מהנושא הקודם והציגו את תוכן הארכיון בלי לחלץ אותו.
חומרה, תהליכים ולוגים

אפשר לבדוק ניצול משאבים דרך כלי מערכת, ולהציג אירועים ביומן של מערכות שמפעילות systemd.

lsblk
free -h
ps -ef | head
journalctl --since "10 minutes ago" -p warning
  • זהו את הדיסק הראשי ואת כמות הזיכרון הזמין. בדקו אילו אירועים מוצגים ומה מקורם.
משתמשים, קבוצות והרשאות

הרשאות מתחלקות לבעלים, לקבוצה ולאחרים. הערכים 4, 2 ו־1 מייצגים קריאה, כתיבה והרצה.

id
touch report.txt
chmod 640 report.txt
ls -l report.txt
  • הסבירו מי יכול לקרוא ומי יכול לערוך את report.txt.
כתובות IP, שער ברירת מחדל ו־DNS

כתובת IP מזהה ממשק ברשת, שער ברירת מחדל מעביר תעבורה לרשת אחרת ו־DNS מתרגם שמות לכתובות.

ip -br address
ip route
getent hosts example.com
  • זהו את כתובת הממשק הפעיל ואת שער ברירת המחדל, ואז בדקו אם פתרון שמות עובד.
